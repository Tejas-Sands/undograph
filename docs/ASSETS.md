# Interface assets

The UndoGraph mark, diagrams, layouts and CSS are repository-native work. No generated bitmap artwork or third-party brand logo is used.

IBM Plex Sans and JetBrains Mono are self-hosted through pinned Fontsource packages. Their SIL Open Font License notices are included in `public/licenses/IBM-Plex-Sans-OFL.txt` and `public/licenses/JetBrains-Mono-OFL.txt`.

Lucide supplies interface icons under the ISC license. React Flow and Dagre supply the graph renderer and layout under MIT licenses. Notices are included in `public/licenses/`. React Flow's on-screen attribution remains visible. See the pinned package versions in `package-lock.json`.

The recorded walkthrough contains curated snapshots from the application's real local synthetic acceptance run. It is permanently labeled recorded and read-only. It omits unrelated failed test runs from the guided sequence; it does not claim to be a complete export of that original test visitor. Every displayed version, dependency, successful run and measured result comes from the captured records. Live exports contain the current visitor's actual history.


The landing-page correction graph is repository-native illustrative UI, permanently labeled synthetic/illustrative. It is not captured inference, telemetry or newly executed agent work. The preservation panel and call-count comparison summarize documented recorded results; the comparison is labeled as one observation. The favicon is a native SVG mark. The landing page uses the existing licensed fonts/icons and adds no external image or font requests. Reference sites informed hierarchy and positioning; no third-party screenshots, logos, copy or artwork are shipped.
